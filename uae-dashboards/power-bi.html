Core DAX Measures & Business Logic

Key business measures copied directly from the semantic model.

Dynamic Metric Selector (Field Parameter / SWITCH)

Allows the executive scorecard and channel comparison visuals to dynamically switch between Revenue, Cases, Margins, and On-Shelf Availability.

Selected metric =
VAR pick = SELECTEDVALUE ( Metric[Metric], "Net sales (AED M)" )
RETURN
    SWITCH (
        pick,
        "Net sales (AED M)", [Net sales] / 1000000,
        "Cases (thousands)", [Cases sold] / 1000,
        "Gross margin (%)", [Gross margin] * 100,
        "Promo share (%)", [Promo share] * 100,
        "On-shelf availability (%)", [On-shelf availability] * 100
    )

Automated Narrative Headline

Identifies the highest-growth channel and largest promotion dependency, writing the insight as plain English above the KPIs.

Headline =
VAR t = ADDCOLUMNS ( VALUES ( Channels[Channel] ), "@g", [Net sales growth], "@p", [Promo share] )
VAR valid = FILTER ( t, NOT ISBLANK ( [@g] ) )
VAR fast = TOPN ( 1, valid, [@g], DESC )
VAR promo = TOPN ( 1, t, [@p], DESC )
VAR promoText = MAXX ( promo, Channels[Channel] ) & " relies most on promotions, at " & FORMAT ( MAXX ( promo, [@p] ), "0%" ) & " of sales."
RETURN
    IF (
        NOT ISEMPTY ( fast ),
        MAXX ( fast, Channels[Channel] ) & " is the fastest-growing channel, up "
            & FORMAT ( MAXX ( fast, [@g] ), "0%" ) & " on the year before, while " & promoText,
        "Select a channel or year to view performance drivers."
    )

On-Shelf Availability (OSA %)

Computes retail execution efficiency by evaluating out-of-stock lost store days against total scheduled retail store days.

On-shelf availability =
1 - DIVIDE ( SUM ( 'Sell Out'[OOS Store Days] ), SUM ( 'Sell Out'[Store Days] ) )

DIFC DAX Measures

Return (Compounded Asset-Weighted)

Return =
VAR selMonths = VALUES ( 'Fund Monthly'[Date] )
RETURN
    IF ( NOT ISEMPTY ( selMonths ), PRODUCTX ( selMonths, 1 + [Monthly return] ) - 1 )

Growth of 100

Growth of 100 =
VAR cur = MAX ( 'Calendar'[Date] )
VAR monthsSoFar = FILTER ( ALLSELECTED ( 'Calendar' ), 'Calendar'[Date] <= cur )
RETURN
    IF (
        NOT ISEMPTY ( VALUES ( 'Fund Monthly'[Date] ) ),
        100 * PRODUCTX ( monthsSoFar, 1 + [Monthly return] )
    )

Dynamic Metric Selector (Calculation Parameter)

Dynamically swaps the visual measure in the community ranking chart based on user slicer selection.

VAR pick = SELECTEDVALUE ( Metric[Metric], "Sales value (AED M)" )
RETURN
    SWITCH (
        pick,
        "Sales value (AED M)", [Sales value] / 1000000,
        "Transactions", [Transactions],
        "Price per sq ft (AED)", [Price per sq ft],
        "Gross yield (%)", [Average gross yield] * 100,

Automated Smart Narrative Headline

Evaluates community yield outliers and automatically generates dynamic English insights above the KPIs.

Headline =
VAR t = ADDCOLUMNS ( VALUES ( Areas[Area] ), "@y", [Average gross yield], "@n", [Transactions] )
VAR valid = FILTER ( t, [@n] >= 10 )
VAR n = COUNTROWS ( valid )
VAR hi = TOPN ( 1, valid, [@y], DESC )
VAR lo = TOPN ( 1, valid, [@y], ASC )
VAR hiName = MAXX ( hi, Areas[Area] )
VAR hiY = MAXX ( hi, [@y] )
VAR loName = MAXX ( lo, Areas[Area] )
VAR loY = MAXX ( lo, [@y] )
RETURN
    SWITCH (
        TRUE (),
        n = 0, "Not enough sales in this selection to compare communities.",
        n = 1, hiName & " sold at AED " & FORMAT ( [Price per sq ft], "#,0" ) & " per sq ft with a " & FORMAT ( hiY, "0.0%" ) & " gross yield.",
        hiName & " pays the most rent for the price at a " & FORMAT ( hiY, "0.0%" ) & " gross yield, "
            & FORMAT ( ( hiY - loY ) * 100, "0.0" ) & " points above " & loName & "."
    )

Average Price Per Square Foot

Measures capital density across transactions, avoiding distorted averages by computing weighted unit price over total aggregate square footage.

Price per sq ft =
DIVIDE ( SUM ( Sales[Price AED] ), SUM ( Sales[Size SqFt] ) )

Off-Plan Market Share (%)

Calculates the proportion of off-plan development transactions relative to total residential deal volume.

Off-plan share =
DIVIDE (
    CALCULATE ( COUNTROWS ( Sales ), Sales[Status] = "Off-plan" ),
    COUNTROWS ( Sales )
)

This module loads the UK Home Office licensed-sponsor list and the Dutch IND recognised-sponsor register (the IND list alone has 13,000+ organisations), then matches employers to them by name. Research project · In progress · Data lineage

Lineage that doesn't guess: tracing data through SQL Server stored procedures

Before a legacy database can be migrated, teams need to know where every number comes from. Much of that logic lives inside stored procedures, in temp tables, variables, cursors and dynamic SQL. That is exactly where today's lineage tools break.

I benchmarked five tools on 12 stored-procedure patterns. The best open-source tool got 9 of 12 right and a commercial tool 10 of 12. None handled dynamic SQL: the open-source tools returned nothing without warning, and the commercial one reported a table that doesn't exist.
